帕鲁的服务端和 Minecraft 不太一样。它吃内存、吃单核，对核心数反而不敏感，还有一个大家都知道的内存泄漏问题——跑上几天就得重启一次。配置买高了纯属浪费，买低了三四个人一起打 Boss 就直接卡成幻灯片。

## 帕鲁服务器到底要买多大

Steam 上帕鲁专用服务端的官方推荐是 4 核 16G，最好 32G 以上，最低 8G 也能跑起来。雨云官方的帕鲁开服教程里写的也是这套数字。

但"官方推荐"和"你和三个朋友玩"是两件完全不同的事。

- **2～4 人小服**：4 核 8G 能跑，前提是别把渲染距离和刷怪量拉满
- **6～10 人常在线**：4 核 8G 会紧，往 4 核 16G 走更稳
- **十几人以上、或者打算长期挂着不关**：6 核 12G 起步，内存越大越省心

真正决定体验的是内存。帕鲁服务端的内存占用会随着游戏时长往上爬，8G 的机器人一多基本靠定期重启续命。雨云官方教程里也给了缓解方案：配置虚拟内存（初始值设成物理内存的 1.5 倍左右，最大值 3 倍），或者用脚本在内存占用超过 90% 时自动重启服务端。

核心数不用追。帕鲁对 CPU 的要求是"单核强"，不是"核心多"。

## 下单前必须定下来的四件事

### 服务器类型：VPS、雨云面板还是 MCSM 面板

雨云游戏云把产品分成了三条线，价格门槛和操作难度都不一样：

- **VPS 服务器**：独立 IP、Windows 远程桌面或 Linux，自由度最高，能装多个服务端、开放 15 个端口，适合已经有开服经验或者想顺便跑别的东西的人
- **雨云面板**：雨云自研的高可用面板，基于 K8s 集群，支持 CPU 升降级、一键开服、可视化管理、备份和 MySQL，适合新手服主和单端场景
- **MCSM 面板**：开源面板，网页全程操作，支持 SFTP，一键自动开服，同样偏新手向

如果你只是想把帕鲁开起来给朋友玩，面板服是省事的那条路；想折腾整合包、同时开两个游戏，VPS 更合适。

### CPU 机型：帕鲁吃单核，别按核心数买

雨云面板服目前公开的机型里，官方教程对帕鲁的建议是选 5900X、Gold 6146、14900KF 这类高主频的，避开 E5 2666V3。原因就是上面说的——单核性能决定服务端 tick 稳不稳。

14900KF / 13900KF 这两个机型是纯大核的（屏蔽了小核），水冷散热超频，单核成绩最猛，但最大只能选到 4 核。帕鲁正好是"4 核够、单核要强"的类型，所以这类机型反而对得上。机型库存会随上架情况变，下单时以购买页实际可选的为准。

### 计费模式：固定计费 vs 动态计费

这是雨云比较有特色的一个选择，也是最容易买错的地方。

- **固定计费**：传统按月固定租金，不产生额外费用，适合每天都在线的长期服
- **动态计费**：低基础月租 + 按每天的 CPU 超额使用率日结，官方叫"CPU 电量"。基准使用率是 20%，低于 20% 不算耗电，超出部分才计费

翻译成人话：**开黑打一周、之后服务器挂着没人上**，选动态计费更省；**一群朋友每天都在线**，固定计费更省心，不用担心月底账单跳一下。

### 公网 IP：NAT 共享还是独立 IP

默认的 NAT 模式是共享公网 IP，没有独立 IP，但可以设置端口映射（不同机型能开的映射条数不一样，常见是 15 条）。做游戏私服够用——帕鲁要用的端口只有一个 8211。

独立公网 IP 需要额外加购。如果你的朋友里有不同运营商、或者你自己不喜欢端口号后面挂着随机数字，多花这笔钱是值得的。

## 开服后最容易踩的三个坑

**内存不够导致的卡顿**。帕鲁服务端的内存占用会持续增长，官方推荐 4 核 16G 不是随便写的。8G 的机器开久了会明显变卡，配虚拟内存或设自动重启能缓解。

**端口没映射**。NAT 模式下必须把 8211 端口映射出去，映射后的公网端口号会随机生成，记得记下来。独立公网 IP 的机器可以跳过这一步。

**误会了"可承载人数"**。雨云购买页上那张"纯净服 12+ 人 / 整合包 1 人"的参考表，基准是 Minecraft 服务器，官方也明确标注了"仅供 MC 服务器参考"。帕鲁的人数和这个不能直接换算。

## 常见问题

**帕鲁服务器一定要 16G 内存吗？**
不一定。4 核 8G 支撑 2～4 个人没问题，只是需要定期重启。人数上到六个以上，8G 就会明显吃力。

**面板服和 VPS 哪个更适合帕鲁？**
只想开个帕鲁服给朋友玩，面板服一键开服最省事。想同时跑别的服务端、或者需要更大的自定义空间，选 VPS。

**动态计费会不会突然很贵？**
动态计费只对 CPU 超出 20% 使用率的部分按天结算，内存和其他硬件不产生"电费"。全天候高负载挂着的情况，反而固定计费更划算。

**买了不合适能退吗？**
支持 7 天无理由退订，每个账号限 3 次。不确定的时候也可以先用 1 元试用一天。

**服务器地址怎么发给朋友？**
进游戏后点「加入多人游戏（专用服务器）」，把控制台里显示的对外地址加端口发出去就行。
